ELP 2026 — SHARED PASSWORD SETUP
=================================

This package uses a Netlify Edge Function to protect the whole site with one shared password.

BEFORE (or immediately after) deploying:
1. Open the existing ELP Netlify project.
2. Go to Project configuration / Site configuration > Environment variables.
3. Add:
       Key:   PROTECTED_PAGE_PASSWORD
       Value: [your shared password]
4. If Netlify asks for a scope, include FUNCTIONS.
5. Save the environment variable.
6. Deploy/redeploy this package. Netlify Edge Function environment-variable changes take
   effect on a new deploy.

DEPLOY:
- Upload this complete project package/folder to the existing Netlify project.
- Keep index.html, netlify.toml, assets/, and netlify/edge-functions/ together.
- The Edge Function is configured for /*, so all site content and direct asset URLs are gated.

BEHAVIOUR:
- Visitors see a branded ELP password screen.
- Successful access lasts 24 hours on that browser/device.
- The top navigation includes a Log out control.
- Changing PROTECTED_PAGE_PASSWORD and redeploying invalidates old sessions.

IMPORTANT:
- This is a shared-password gate, not per-user authentication.
- Do not hard-code the password into index.html or netlify.toml.
